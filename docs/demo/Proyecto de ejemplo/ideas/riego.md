# Sistema de riego

Elegimos **goteo con temporizador**: gasta poca agua y no depende de que alguien se acuerde cada día.

- Un grifo del patio alimenta la línea principal.
- Cada bancal tiene su llave para cortarlo por separado.
- En verano, el temporizador riega 15 minutos al amanecer.

Coste incluido en el [presupuesto](presupuesto.md).
